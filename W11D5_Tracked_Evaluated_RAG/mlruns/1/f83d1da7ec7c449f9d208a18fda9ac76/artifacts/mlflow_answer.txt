Question:
What is RAG?

Answer:
RAG (Retrieval-Augmented Generation) is a technique that combines information retrieval with text generation. Instead of depending only on information stored in a language model, a RAG system first retrieves relevant information from a knowledge base and then provides that information to a language model to generate an answer.

A typical RAG pipeline has several stages: document loading, text splitting, embedding generation, vector storage, retrieval, and answer generation.
